# Swap o Chatarra – calculadoras

Web estática generada con `node build.js` a partir de `data/motores.json`.

- Cloudflare Pages: comando de build `node build.js`, carpeta de salida `dist`.
- Para añadir un motor: nueva entrada en `data/motores.json` con sus fuentes.
- Enlace de afiliado: `data/config.json` → `afiliado.enlace_kit_distribucion`.
